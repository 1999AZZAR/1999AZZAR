Saya menulis firmware yang berbicara dengan dunia fisik — dan dashboard yang membuat percakapan itu terbaca oleh manusia.

Dengan surat ini saya menyatakan minat saya pada posisi IoT dan otomasi di [Nama Perusahaan]. Selama lima tahun terakhir saya telah mengirimkan sistem terhubung secara end-to-end: firmware ESP32 dan STM32, pipeline MQTT, REST dan WebSocket API, dashboard telemetry berbasis React, dan loop kontrol yang berjalan di baliknya. Karya produksi terbaru saya mencakup stack telemetri multi-sensor pada ESP32 (SHT20, termistor, sensor gas MQ-137), pengendali suhu fuzzy-plus-PID yang di-tuning dengan Ziegler–Nichols dan Cohen–Coon, serta sistem akses RFID dengan kontrol relay dan notifikasi Telegram pada ESP8266. Saya memegang sertifikasi BNSP IoT Practitioner (2024) dan telah terverifikasi secara formal di HackerRank untuk problem-solving, Python, SQL, dan REST API.

Saya bekerja dengan nyaman di lintas stack yang menjadi cakupan peran ini. Di sisi perangkat saya menulis C/C++ yang bersih untuk STM32 HAL, kode Arduino-core untuk ESP32/ESP8266, dan Python untuk tooling serta rig uji. Di sisi cloud saya men-deploy service terkontainerisasi di AWS dan GCP dengan Docker dan Kubernetes, menghubungkan broker MQTT (Mosquitto, EMQX, AWS IoT Core) ke backend Node.js dan Django, dan menampilkan data lewat dashboard React + Next.js dengan WebSocket untuk pembaruan langsung. Saya telah mengimplementasikan pengendali PID, Fuzzy Logic, dan LQR serta menjalankan eksperimen auto-tuning dengan algoritma genetika; saya memilih loop yang tepat untuk plant, bukan mempertahankan satu metode favorit.

Alasan kecocokan untuk peran ini:
  • 5+ tahun mengirimkan produk IoT dari skematik hingga dashboard, dengan portofolio sistem live dan 30+ repositori terbuka.
  • Firmware produksi di ESP32, STM32, dan Arduino; integrasi sensor suhu, kelembapan, gas, RFID, dan beban relay.
  • Kedalaman sistem kontrol: PID dengan Ziegler–Nichols dan Cohen–Coon, supervisor Fuzzy Logic, LQR; simulasi MATLAB hingga deployment embedded.
  • Stack telemetri cloud: MQTT, API Node.js / Django, PostgreSQL, caching Redis, dan dashboard React dengan feed WebSocket live.
  • BNSP IoT Practitioner (2024) dan portofolio 20+ sertifikasi yang mencakup embedded, ML, dan delivery web modern.
