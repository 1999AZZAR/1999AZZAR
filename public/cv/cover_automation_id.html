Yth. Bapak/Ibu Perekrut,

Saya membangun tooling yang memindahkan manusia dari pekerjaan repetitif — agen AI yang bertindak, browser runner yang tak pernah tidur, dan lapisan skill MCP yang memberi model bahasa kemampuan nyata untuk bertindak.

Dengan surat ini saya menyatakan minat untuk bergabung dengan [Nama Perusahaan] sebagai engineer otomasi dan AI tooling. Pekerjaan saya berada di persimpangan antara desain agen AI, developer tooling, dan otomasi web: saya membuat server Model Context Protocol (MCP) dan library skill terpaket yang memperluas Claude dan model bahasa lainnya dengan akses tool kelas pertama — sistem file, eksekusi shell, pencarian web, memori terstruktur, telemetri IoT, dan API eksternal — semuanya diorkestrasi melalui antarmuka bertipe dan dapat dikomposisi. Ini bukan sekadar wrapper; melainkan tool chain berkelas produksi dengan kontrak error, penanganan rate-limit, dan output skema yang dapat diandalkan oleh model bahasa dalam loop penalaran multi-langkah.

Di sisi browser automation, saya menggunakan Playwright dan Puppeteer untuk ekstraksi end-to-end, pengujian interaksi, dan eksekusi alur kerja headless. Saya telah membangun pipeline yang menavigasi UI terotentikasi, melakukan scraping data terstruktur di permukaan yang penuh JavaScript atau terpaginasi, dan menghasilkan output bersih ke API atau database downstream — dengan kendali fingerprint Chromium dan persistensi sesi saat diperlukan. Pipeline ini saya integrasikan ke GitHub Actions atau Docker Compose agar dapat berjalan terjadwal, berbasis event, atau on-demand di dalam CI gate. Ketika tugas memerlukan visual assertion browser nyata atau pengujian regresi pixel-diff, saya menulis itu juga.

Alasan kecocokan untuk peran ini:
  • Pembuatan server MCP: skema tool bertipe, endpoint resource, dan perlindungan prompt injection untuk agen berbasis Claude maupun OpenAI-compatible.
  • Pengemasan skill agen: library skill yang dapat digunakan ulang (pengorganisasi file, pemindai keamanan, arsitektur IoT, pemroses PDF, penanganan XLSX) yang dideploy ke lingkungan Claude Code produksi.
  • Otomasi browser: pipeline Playwright/Puppeteer untuk ekstraksi data, replay sesi terotentikasi, dan regresi visual di SPA dinamis.
  • Orkestrasi workflow: multi-agent fan-out dengan sequential thinking, tool chaining paralel, state sesi berbasis Redis, dan kontrak skema JSON terstruktur.
  • Fondasi full-stack: Python, TypeScript, Node.js, Docker, dan GitHub Actions — sehingga otomasi tidak pernah berdiri sendiri terpisah dari sistem yang dilayaninya.

Yang saya anggap menarik dari domain ini adalah bahwa otomasi yang baik memerlukan ketelitian yang sama dengan perangkat lunak yang baik: kontrak yang jelas, mode kegagalan yang dapat diamati, dan disiplin untuk berhenti mengotomasi di batas di mana keputusan manusia sungguh-sungguh diperlukan. Standar itu saya terapkan baik saat menulis scraper Playwright, merancang tool chain MCP multi-langkah, maupun menyambungkan skill agen yang menjalankan perintah shell atas nama model bahasa. Keamanan bukan langkah akhir — sanitasi input, pembatasan izin, dan isolasi kredensial adalah bagian dari setiap tool yang saya kirim.
